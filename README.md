An interactive, browser-based quiz application built using HTML, CSS, and JavaScript. The application presents multiple-choice questions about programming, AI, software development, and computer science concepts, then displays the user's final score.

Features
Multiple-choice questions: Each question provides four answer options.
Interactive interface: Select an answer by clicking an option.
Score tracking: Correct answers increase the user's score.
Automatic progression: Selecting an answer moves the quiz to the next question.
Final results: Displays the total score after all questions are answered.
Responsive styling: Uses a flexible layout designed to fit different screen widths.
Separate source files: HTML, CSS, and JavaScript are organized into separate files.
Technologies Used
HTML5 — Structures the quiz interface.
CSS3 — Handles styling, layout, colors, and interactive button effects.
JavaScript — Manages questions, answer validation, score calculation, and quiz progression.

Getting Started
Prerequisites
You only need a modern web browser, such as Google Chrome, Microsoft Edge, or Firefox. No additional packages or installations are required.

Installation and Usage
Clone the repository:

git clone https://github.com/vinisepat25bcon/Quiz_25BCON1058.git
Open the project folder:

cd Quiz-25BOCN1058
Open index.html in your web browser.

Read each question and click an answer option to continue.

Complete all questions to view your final score.

How It Works
The questions, answer options, and correct answers are stored in a JavaScript array.
JavaScript displays the current question and creates a button for each answer option.
When an option is selected, the application checks whether it matches the correct answer.
The score is updated for correct answers, and the next question is displayed.
After the final question, the application displays the user's score.
